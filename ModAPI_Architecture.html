Mod Apply Pipeline — ApplyMods() Flow
◆ Backup Exists?
Check gamefiles/original/{GameId}/
✓ YES
Read assemblies from backup. Game folder untouched — no file lock risk.
✗ NO
Auto-create backup from {GamePath}. Copy all IncludeAssemblies + CopyAssemblies. (v2.0.9619)
🔍 Assembly Resolver Setup
CustomAssemblyResolver search paths from backup folders only.
Game install folder added only when backup doesn't exist — prevents Cecil file locks on game DLLs. (v2.0.9619)
📖 Read Assemblies (Cecil)
ModuleDefinition.ReadModule() from gamefiles/original/.
IncludeAssemblies: full IL parse + modification.
CopyAssemblies: resolve mscorlib / UnityEngine references.
✏️ IL Modification
Inject mod code into game assemblies: InjectInto, AddMethod, AddField, AddClass.
Add BaseModLib assembly reference.
Remap all references via AssemblyVersionMap.
💾 Write to Staging
Modified assemblies written to gamefiles/modded/{GameId}/.
PE header patched: v4.0.30319 → v2.0.50727.
📦 Deploy to Game Folder
DirectoryCopy(): gamefiles/modded/ → actual game install path.
No file lock conflicts because all reads came from backup folder.
